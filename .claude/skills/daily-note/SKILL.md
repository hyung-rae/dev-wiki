# 데일리 체크리스트 업데이트

## 개요

데일리 기록은 **루트의 단일 문서** `데일리 체크리스트.md` 하나로 관리한다.
날짜별 파일을 새로 만들지 않고, 이 문서 안에 **`## YYYY-MM-DD` 섹션을 최신순(맨 위)으로 누적**한다.

"데일리 체크리스트"(또는 "데일리 노트 생성") 호출 시 아래 4단계를 순서대로 실행한다.

## 문서 구조

```markdown
## 2026-08-26
### 오늘 일정
- [<] 10:30 [큐] 큐샵 데일리 스크럼
### 오늘 할 일
- [/] 아웃블로그 SLP
### 팔로업
- [!] 🐛 bug list

## 2026-08-25
### 오늘 일정
...
```

- **frontmatter·H1 없음.** 문서 제목은 파일명(`데일리 체크리스트.md`)으로 식별한다.
- 날짜 섹션은 `## YYYY-MM-DD` (요일 표기 없음), **최신 날짜가 항상 맨 위**.
- 하위 섹션은 `### 오늘 일정` / `### 오늘 할 일` / `### 팔로업` 세 개 고정. 별도 `메모` 섹션은 두지 않으며 메모성 항목도 `### 팔로업`에 기록한다.
- 날짜 섹션 사이에는 빈 줄 1개, 같은 날짜 블록 안의 `###` 섹션 사이에는 빈 줄을 두지 않는다.
- 과거 날짜 섹션은 **수정하지 않고 그대로 남긴다** (그날의 기록 = 히스토리).

## 절차

### Step 1 — 문서·오늘 섹션 확인

- 오늘 날짜(`currentDate` 컨텍스트 또는 `date` 명령으로 확인)를 구한다.
- 대상 파일: `/Users/hyung-rae/Desktop/dev-wiki/데일리 체크리스트.md`
  - 파일이 없으면 새로 만들고 Step 2로 진행한다 (이월 대상 없음).
- 파일 맨 위에 **오늘 날짜 섹션(`## YYYY-MM-DD`)이 이미 있으면**:
  - 새 섹션을 만들지 않는다. **Step 4(캘린더)만 다시 실행해 `### 오늘 일정`을 최신 상태로 갱신**하고, `### 오늘 할 일`·`### 팔로업`은 손대지 않는다.
  - 사용자에게 "오늘 섹션이 이미 있어 일정만 갱신했다"고 알리고 종료한다.
- 없으면 Step 2로 진행한다.

### Step 2 — 오늘 날짜 섹션 추가

문서 **맨 위**에 아래 블록을 삽입하고, 기존 내용(직전 날짜 섹션부터) 앞에 빈 줄 1개를 둔다.

```markdown
## YYYY-MM-DD
### 오늘 일정
### 오늘 할 일
- [ ] 
### 팔로업
```

### Step 3 — 직전 날짜 섹션에서 미완료 항목 이월

- 문서에서 **오늘 바로 아래(= 직전 날짜) 섹션**을 읽는다. 없으면 이 단계를 건너뛴다.
- 직전 섹션의 **`### 오늘 할 일`, `### 팔로업`** 두 섹션을 각각 읽어, **완료·취소되지 않은 항목만** 오늘 섹션의 같은 섹션으로 그대로 복사한다.
  - **제외**: `- [x]`(완료), `- [-]`(취소) 항목 — 이 둘만 이월에서 빠진다.
  - **제외**: 내용 없는 빈 placeholder (`- [ ]` 뒤에 텍스트 없음).
  - 그 외 항목(`- [ ]` 미완료, `- [/]` 진행중, `- [!]` 중요, `- [?]` 확인필요, `- [*]`, `- [<]`, `- [b]`, `- [f]`, `- [i]` 등)은 아이콘을 원본 그대로 유지해 이월한다.
  - **하위 항목(들여쓴 체크박스·설명 줄)은 상위 항목과 함께 통째로 이월**한다. 단, 상위 항목이 이월 대상일 때 그 아래 `- [x]`·`- [-]` 하위 항목은 맥락상 필요하면 남겨도 된다 (예: 단계별 진행 상황).
  - **`- [/]` 진행중 항목은 완료(`[x]`)·취소(`[-]`)로 바뀌기 전까지 매일 이어서 이월한다** (중간에 끊기지 않도록 주의).
  - 출처 날짜를 뒤에 추가하지 않는다 (원본 텍스트 그대로).
- `### 오늘 일정`은 이월하지 않는다 (매일 새로 채운다).
- 이월 결과 `### 오늘 할 일`이 비면 빈 `- [ ] ` 한 줄을 남긴다.
- **직전 날짜 섹션은 수정하지 않는다** (원본 그대로 히스토리로 보존).

### Step 4 — Google Calendar 일정 추가

- `mcp__claude_ai_Google_Calendar__list_events`를 호출해 오늘 날짜 이벤트를 가져온다.
  - startTime: `YYYY-MM-DDT00:00:00`, endTime: `YYYY-MM-DDT23:59:59`, timeZone: `Asia/Seoul`, orderBy: `startTime`
  - 사용자 캘린더(`rea1109@squares.ai`)와 스퀘어스 공유 캘린더(`sqs@squares.ai`) 모두 조회한다.
- `rea1109@squares.ai`가 attendees에 포함된 이벤트만 오늘 섹션의 `### 오늘 일정`에 시간순으로 삽입한다.
  - 형식: `- [<] HH:MM 이벤트명` (Minimal 테마 Schedule 아이콘)
  - 종일 이벤트: `- [<] (종일) 이벤트명`
- 인증 안 됨, 연결 불가, 일정 없음의 경우 섹션을 빈 채로 두고 계속 진행한다.
