==고차 함수(HOF, high order function)는 함수를 반환하는 함수==다. 반환된 함수를 실행하려면 괄호를 한 번 더 붙여야 한다.

```javascript
function a() {          // 외부 함수
  return function bbb() {  // 내부 함수
    console.log("hello");
  };
}

a();    // bbb 함수 자체가 나온다 (실행되지 않는다)
a()();  // a()의 결과를 실행 → "hello"
```

## 클로저
내부 함수는 **외부 함수의 인자와 지역 변수에 계속 접근할 수 있다.** 외부 함수의 실행이 끝난 뒤에도 그렇다. 이렇게 ==함수가 자신이 선언된 환경을 기억하는 성질==이 클로저다.

```javascript
function makeCounter(start) {
  let count = start;      // 외부 함수의 지역 변수
  return function () {
    count += 1;           // 외부 함수가 끝난 뒤에도 살아있다
    return count;
  };
}

const counter = makeCounter(10);
counter(); // 11
counter(); // 12
```

클로저 덕분에 **외부에서 직접 건드릴 수 없는 값**을 함수 안에 숨겨둘 수 있다.
