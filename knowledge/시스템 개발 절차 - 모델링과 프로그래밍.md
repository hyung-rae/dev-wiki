여기서 **System**이란 컴퓨터에서 사용하는 앱 전부, 곧 ==오프라인에서 하던 일을 컴퓨터에서 하게 만든 것==이다. 그 시스템을 만드는 과정은 **코딩 전과 코딩**으로 나뉜다.

| | modelling | programming |
| --- | --- | --- |
| **시점** | 코딩 **전** | 실제 구현 |
| **하는 일** | 시스템 정의, 요구사항 정의(owner가 요구한), 구체적인 계획(분석·설계) | 소스코드, 컴파일, 디버깅 |
| **결과물** | **model** | 코드를 포함한 **System** |
| **표기법 / 언어** | UML | 분석·설계 단계에서 정한 언어 |

> [!tip]
> **모델링은 "코딩 전에 결정하는 모든 활동"** 이다. 무엇을 만들지·어떤 언어로 만들지가 여기서 정해지고, 프로그래밍은 그 결정을 코드로 옮기는 단계다.
