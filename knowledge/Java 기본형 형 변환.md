==형 변환(Type Casting)==은 값을 특정 자료형으로 바꾸는 것이다. **어느 방향으로 가느냐**에 따라 Java가 알아서 해주기도 하고, 개발자가 명시해야 하기도 한다.

| 구분 | 방향 | 문법 |
| --- | --- | --- |
| **암시적**(implicit) | 작은 타입 → 큰 공간, 정수 → 실수 | 자동 |
| **명시적**(explicit) | 큰 타입 → 작은 공간, 실수 → 정수 | `(바꿀타입)값` |

```java
// 암시적 — byte(8bit)를 int(32bit)에 담으므로 자동
byte b = 30;
int number = b;
double d = b;

// 명시적 — double을 int에 담으므로 (int) 필요, 소수점 버려짐
d = 1.283;
number = (int) d;
```

## 오버플로우 / 언더플로우
타입의 표현 범위를 넘기면 **값이 반대편 끝으로 순환**한다. 명시적 형 변환에서 자주 만난다.

```java
byte b;                    // -128 ~ 127
b = (byte) 128;   // -128   오버플로우: 최댓값을 넘어 음의 최솟값으로
b = (byte) -129;  //  127   언더플로우: 최솟값을 넘어 양의 최댓값으로
```

> [!warning]
> 명시적 형 변환은 **컴파일러에게 "손실을 감수하겠다"고 선언**하는 것이다. 에러가 사라졌다고 값이 보존된 것은 아니다.
