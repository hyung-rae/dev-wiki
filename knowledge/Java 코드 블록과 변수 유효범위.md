**한 쌍의 `{}` 안에 있는 모든 코드**를 코드 블록이라 한다. 블록은 하위 블록을 중첩해 가질 수 있고, 코드 블록이 중요한 이유는 ==변수의 유효범위와 직결==되기 때문이다.

## 유효범위 규칙
- 변수가 **선언된 시점부터, 그 변수가 속한 코드 블록이 끝날 때까지**가 유효범위
- **같은 유효범위 안에서는 동일한 이름의 변수를 다시 만들 수 없다**

```java
for (int i = 0; i < 3; i++) {
    int number = i * 2;   // 매 반복마다 블록이 끝나며 사라진다
}
// 여기서는 i도 number도 존재하지 않는다
```

> [!tip]
> "이 변수가 왜 여기선 안 보이지?"의 답은 대부분 **어느 `{}` 안에서 선언했는가**에 있다.
